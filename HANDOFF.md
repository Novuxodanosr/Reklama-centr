# Reklama Centr — передача проекта

Сайт рекламно-производственной компании Reklama Centr (Ташкент).
Отдельный сайт для производственного направления; сайт ps.com.uz
к нему отношения не имеет и в текстах не упоминается.

## Стек

Next.js 14.2.35 (App Router), TypeScript, Tailwind, next-intl, framer-motion.
Три языка: RU (корень `/`), EN (`/en`), UZ (`/uz`).
Шрифты: Unbounded (заголовки) + Golos Text (текст), грузятся через next/font.

Запуск для заказчика: двойной щелчок по `ЗАПУСК-САЙТА.bat` в папке сайта
(ярлык «Сайт Reklama Centr» на рабочем столе) — откроется окно сервера и
браузер с http://localhost:3000. Окно нужно держать открытым; закрыли — сайт
выключился. Для разработчика: `npm install`, затем `npm run dev`.
Сборка: `npm run build`, запуск собранного: `npm start`.

## Дизайн (переделан 11.09.2026)

Первая версия была похожа на ps.com.uz — заказчик потребовал другой, «максимально
крутой и интерактивный» дизайн. Исследованы сайты производителей рекламы в США,
Европе, Казахстане и России; на их основе сделана тёмная «индустриальная» тема.

- Палитра: почти чёрный фон (#0B0B0D), светлый текст, фирменный красный (#E4142F). Тёмная тема.
- Шрифты: Sofia Sans Extra Condensed (крупные плотные заголовки, как на вывесках) + Onest (текст), оба с кириллицей, грузятся через next/font. НЕ Commissioner/Inter от ps.com.uz.
- Интерактив: анимации при прокрутке (framer-motion), «наезд» на фото в шапке, счётчики цифр, бегущая строка направлений с фактами доверия, «гармошка» девяти направлений на главной, лента работ с лайтбоксом (стрелки, Esc, свайп), фильтр портфолио, параллакс в блоке производства, линия прогресса на шагах, две встречные ленты логотипов клиентов.
- Первый экран (13.09.2026): слайдер из 10 реальных проектов (список `slides` в
  `components/Hero.tsx`), каждые 4,5 с фото сменяется с наездом, слово в
  заголовке «Производим …» прокручивается (`hero.rotate.words` в messages),
  подпись проекта и полоски-прогресс внизу (клик — переход на слайд, наведение —
  пауза), крупный номер слайда справа, параллакс и красная подсветка от курсора
  (только мышь, без тач). При prefers-reduced-motion слайды не крутятся.
  Заменить фото слайда — в `slides` (image + work для подписи).
- Заявка переделана в 3 шага (направление → описание+файл → контакты), с загрузкой эскиза (до 10 МБ, уходит в Telegram отдельным файлом).
- Мессенджеры: кнопка Telegram в шапке, липкая панель «Позвонить / Telegram» внизу на телефонах.
- Фирменный мотив — деления линейки (как измерительная лента в цехе).
- Логотипы клиентов — цветные, на сплошной белой полосе через всю ширину, без
  плашек (решение заказчика 12.09.2026). Заголовок блока короткий и нейтральный «Клиенты»: слово «доверяют» заказчик отверг — не все бренды знают о публикации.

Исследование индустрии (полные отчёты по США, Европе, Казахстану, России) — в истории этой сессии.

## «Светящаяся» динамика сайта (24.09.2026)
Концепция: сайт ведёт себя как продукция компании (световые буквы, LED, лайтбоксы). Без WebGL и новых библиотек,
~10 КБ gzip кода + ~2 КБ CSS.
- `components/fx/Effects.tsx` (в layout): заголовки h2 в main «зажигаются» при появлении (класс neon → lit, мерцание
  + свечение), страховка — проверка при прокрутке; карточки `data-tilt` наклоняются за курсором с подсветкой рамки;
  `data-clip` — раскрытие «шторкой»; магнитные кнопки (.btn-primary/.btn-ghost, свойство translate); кольцо-курсор
  (только мышь); полоса прогресса прокрутки.
- `components/fx/LedField.tsx` — LED-сетка на первом экране: точки загораются вокруг курсора; на телефоне — волна.
  Canvas рисует только светящиеся точки, ~45 кадров/с, пауза вне экрана и в фоновой вкладке.
- Бегущая строка — LED-табло (`.led-screen`: точечная маска + свечение акцентов).
- `components/SignDesigner.tsx` — «Зажгите своё название»: ввод названия, 3 типа подсветки (световые буквы / гибкий
  неон / контражур), 5 цветов, вкл/выкл; кнопка ведёт в форму с заполненным описанием
  (`/contacts?service=outdoor&message=…` → LeadForm сразу на шаге «Детали»). Идея из обзора: у производителей
  вывесок главный приём — живой конструктор.
- `app/[locale]/template.tsx` — плавное появление страниц (только opacity, иначе ломается fixed у лайтбокса).
- Лёгкий режим (класс `fx-lite`): prefers-reduced-motion, saveData, ≤4 ядер или ≤2 ГБ памяти → эффекты выключены,
  контент виден сразу. Lighthouse до/после НЕ замерялся (нужна сборка с остановкой dev-сервера).
